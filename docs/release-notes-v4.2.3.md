# PoENavi v4.2.3 リリースノート

## PoE2のリーグ一覧取得を改善

- 公式APIが一時的にStandard／Hardcoreだけを返した場合、不完全な応答として別の公式URLから再取得するようにしました
- 両方の取得に失敗した場合は、直前の正常な一覧または予備一覧を維持するようにしました
- 検索結果画面とぽえとれ設定画面へ「再取得」ボタンを追加しました

## 「スキルを付与」の検索に対応

- 公式Trade検索用Stat IDがある付与スキルを検索条件へ表示するようにしました
- 付与スキルは初期状態でチェックONになります
- レベル付きスキルは、そのレベルを最低値として検索します
- 公式Trade検索用Stat IDがないスキルは表示・検索対象にしません

## PoE2の出品価格アイコンを追加

- ミラー、錬金、増強、可能性、変成、王者、ヴァールの各オーブを、数字と通貨アイコンの組み合わせで表示するようにしました

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
