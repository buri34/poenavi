# PoENavi v3.3.1 リリースノート

## ぽえとれのMod表示を改善

- 同じアイテムを連続して検索した際も、Mod条件が途中で畳まれず、すべて見える状態を維持するように修正
- 完成品装備のMod表示順を「最終性能 → Prefix系統 → Suffix系統 → その他」へ整理
- 集約pseudo、Crafted、Fracturedも元ModのPrefix／Suffix系統へ分類し、各系統内はアイテムの記載順を維持

## v3.3.0からの変更範囲

- 対象コミット: `v3.3.0..v3.3.1`
- PoE1モードのぽえとれMod表示と連続検索時のレイアウトを更新
