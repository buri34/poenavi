# PoENavi v3.3.0 リリースノート

## ぽえとれの画面デザインを刷新

- PoE1モードのぽえとれを、暗いニュートラル背景と青緑アクセントの見やすい配色へ変更
- Mod条件、検索操作、価格一覧の列幅・余白・文字サイズを整理し、情報密度を均一化
- 小／中／大の表示サイズに合わせて、入力欄や操作ボタンが自然に収まるレイアウトへ改善
- 固定値の検索条件を簡略表示し、操作できる項目が分かりやすい見た目へ変更
- poe.ninja参考価格と推移表示をまとめ、検索結果の要約を簡潔に整理

## 価格検索の精度を改善

- Magebloodのフラスコ本数を実際のMod値から判定し、poe.ninjaの対応バリエーションと照合
- 使用不可アイテムのヘッダー表記を解析できるようにし、対象アイテムの取り込み漏れを修正
- 長いMod文章のツールチップ表示と、最小・最大入力欄の視認性・操作性を改善

## v3.2.4からの変更範囲

- 対象コミット: `v3.2.4..v3.3.0`
- PoE1モードのぽえとれUI、価格検索、アイテム解析を更新
