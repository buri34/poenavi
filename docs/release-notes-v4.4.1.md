# PoENavi v4.4.1 リリースノート

## アビス冒涜Modチェックの認識精度を改善

- 折り返された長文Mod、小数点、短い`+数値`など、Windows OCRで起きる読取欠落への安全な補正を追加しました
- 通常のWindows OCRで数値だけを確認できなかった場合に限り、NDLOCR-Liteを使った高精度OCRで再確認します
- Windows OCRで確定済みの結果は高精度OCRで上書きせず、本文と数値の対応が一致した場合だけ結果を採用します
- 実際に報告された7画像・21Modを回帰データへ追加し、すべて期待Tierへ解決できることを確認しました

## 高精度OCRパックを必要な人だけ自動取得

- PoENavi本体を従来の自動更新で安全に展開できるサイズへ戻しました
- アビス冒涜Modチェックの管理画面を初めて開いた時に、高精度OCRパックをバックグラウンドで自動取得します
- 取得状況、完了、エラーは管理画面内に表示され、エラー時は「再試行」できます
- 一度準備した高精度OCRパックはPoENavi更新後も再利用するため、毎回のダウンロードはありません
- 準備中や通信失敗時も、従来のWindows OCRによる読み取りは引き続き利用できます

## 高精度OCRの待ち時間を短縮

- 高精度OCRは必要になった時だけ起動し、連続して冒涜Modを確認する間はロード済みモデルを再利用します
- 起動後はアビス冒涜Modチェックの操作から3分間保持し、利用が止まると自動終了してメモリを解放します
- 初回準備中と再確認中はゲーム画面右上へ理由と進行状況を表示します
- 進行表示を16px・やや太字・白文字＋黒縁へ変更し、明るいゲーム背景でも読みやすくしました

## プライバシーと安全性

- 高精度OCRパックはSHA-256を検証し、安全性を確認してから展開します
- OCR画像と認識文字列はPC内で処理し、外部サービスへ送信しません
- NDLOCR-Lite 1.3.1、CPUランタイム、学習済みモデル、必要なライセンスは高精度OCRパックに含まれます

※高精度OCRが初めて必要になった時は、モデル起動に10～15秒ほどかかる場合があります。3分以内の再利用時はモデルを再読込しません。

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
