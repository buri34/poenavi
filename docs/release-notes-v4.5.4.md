# PoENavi v4.5.4 リリースノート

## ぽえとれのアップデート通知を改善

- ぽえとれ起動中に1時間ごとに新しいバージョンを自動確認するようにしました
- 新しいバージョンがある場合、ぽえとれのメイン画面下部に「アップデートあり」ボタンを表示します
- ボタンから従来のアップデート画面を開き、そのまま更新できます
- 一時的な通信失敗では操作を妨げず、次回の定期確認で再試行します

## PoE 1 3.30のCurrency Exchange候補を更新

- アストロラーベ、ソウルコア、オールフレイムなど、リーグ開始後に確認できた14品を追加しました
- 「謎のスレッド」と「謎のアストロラーベ」を追加しました
- 「メイヴェンのスレッドのチゼル」と「スレッドのデリリウムオーブ」を3.30の現行名へ更新しました
- 廃止された旧アストロラーベやフラグメント、無効化された占いカードなど、旧候補25件を表示しないようにしました

## 注意事項

- 本バージョンはコード署名証明書を使用していません
- zipダウンロード時にWindows DefenderやSmartScreenで警告される場合があります。ダウンロード元と公開ハッシュを確認のうえ利用してください
