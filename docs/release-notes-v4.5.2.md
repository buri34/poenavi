# PoENavi v4.5.2 リリースノート

## PoE 1「Coven of Umbra」リーグ開始前対応

- 新スキルジェム「アーケインリンク」をジェム取得支援へ追加しました
- サイオンのクエスト報酬と、マローダー／デュエリスト／テンプラーの店売り解禁タイミングを反映しました
- PoE 1のCurrency Exchangeから廃止されたスカラベカテゴリと旧候補を表示せず、過去設定から価格照会もしないようにしました
- Currency Exchangeへ追加された5品の正式ID・日英名・カテゴリと、市場データ連動を検証しました

## アップデート確認メッセージの可読性を修正

- 設定画面の「アップデートを確認」から表示するメッセージが、Windowsの白背景で読めなくなる問題を修正しました
- 最新版の案内、確認失敗、ダウンロード失敗、適用確認、Updater起動失敗の各メッセージで背景色・文字色・ボタン色を明示しました

## 注意事項

- 本バージョンはコード署名証明書を使用していません
- zipダウンロード時にWindows DefenderやSmartScreenで警告される場合があります。ダウンロード元と公開ハッシュを確認のうえ利用してください
