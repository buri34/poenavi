# PoENavi v4.1.8 リリースノート

## ぽえとれのPoE2検索を改善

- 石板のレアリティ検索を、読み取ったアイテムに合わせて切り替えられるようにしました
- ユニーク石板のバイオーム条件を検索に使用できるようにしました
- 「すべての指輪」検索でマジック完全一致が維持されない問題を修正しました
- ユニーク武器でローカルModが優先されない場合がある問題を修正しました
- 複数行Mod、日本語アイテム名、拡張ソケットの解析精度を改善しました

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
