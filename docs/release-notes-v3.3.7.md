# PoENavi v3.3.7 リリースノート

## みになびをOBSのウィンドウキャプチャに対応

- みになびをOBS Studioの「ウィンドウキャプチャ」で取り込めるようにしました
- OBSでは「みになび - OBSキャプチャ」として選択できます
- みになびをOFFにしてもキャプチャ対象を維持し、ONにすると同じウィンドウへ表示します
- ON/OFFのたびにOBS側でウィンドウを選び直す必要はありません
- 待機中のウィンドウは画面端へ極小・透明で収納され、通常利用では目立ちません
- 初回ON時にウィンドウが一時的に大きく表示される問題も修正しました

## ぽえなびUIの表示調整

- タイマーとガイドの「切り離す」ボタン右側へ余白を追加しました
- ホットキー設定画面の「操作モード」「AUTO-HIDE」を、通常のホットキー欄と同じ横幅へ調整しました
- タイマーの「直近／遅い区間」が上下に見切れる問題を修正しました
- 切り離しタイマーに古い小さなウィンドウサイズが保存されていても、必要な高さまで自動で広がるようにしました

## push前セキュリティー検査を強化

- ローカルのpre-pushフックとGitHub Actionsで、同じセキュリティー検査を実行する二重構成を追加しました
- GlassWormで悪用される補助異体字セレクターや、異常なVariation Selectorを検出します
- 双方向制御文字、ゼロ幅制御文字、埋め込みBOM、秘密情報形式も検査します
- 正当な絵文字用Variation Selectorとファイル先頭のBOMは許可します
