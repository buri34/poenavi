# PoENavi v3.3.9 リリースノート

## ぽえとれの公式Trade API通信を改善

- 通常の価格検索で取得する出品を上位20件に固定しました
- 同じ出品者の出品が多い場合に、最大100件まで自動取得していた処理を廃止しました
- 通常の価格検索は、検索1回と詳細取得2回までの合計3通信で完了します
- PoE公式Trade APIが返す利用制限情報を読み取り、検索APIと詳細取得APIの通信間隔を個別に調整するようにしました
- 長い待機が必要な場合は検索を待ち行列へ追加せず、再検索できるまでの目安時間を表示します
- APIの利用枠に余裕がある通常時は、追加の待ち時間を発生させません
