# PoENavi v4.5.1 リリースノート

## ぽえとれの検索開始を高速化

- PoE1／PoE2のアイテム解析で利用するデータ索引を事前に準備し、検索開始時の待ち時間を短縮しました
- 価格検索と検索結果画面の準備を並行して進めるようにし、操作後の応答を改善しました

## Currency Exchangeレート表示を改善

- 交換元・交換先の表示位置と数値の揃え方を見直し、複数レートを比較しやすくしました
- 不要な補助表示を整理し、レート一覧をより簡潔にしました

## ハイストOCRの誤判定を抑制

- 複数候補へ曖昧に一致する展示品やModを確定しないようにし、誤った価格検索へ進む可能性を減らしました

## 高精度OCRパックの再試行を改善

- ダウンロードや準備に失敗した直後でも、設定画面からすぐ再試行できるようにしました

## 隠れ家滞在通知の設定を修正

- 設定画面でPoE1／PoE2を切り替えた時、それぞれの`Client.txt`パスを正しく表示・保存するよう修正しました
- 既知のインストール先から別モードのパスが誤保存されたと確認できる場合は、正しいパスを自動検出して修復します
- 通知音の「試聴」ボタンを`Client.txt`設定より上へ移動しました

## 設定保存の安全性を改善

- 設定ファイルを一時ファイルへ書き込んでから置き換える方式に変更し、保存中断時に設定が破損する可能性を減らしました

## 注意事項

- 本バージョンはコード署名証明書を使用していません
- zipダウンロード時にWindows DefenderやSmartScreenで警告される場合があります。ダウンロード元と公開ハッシュを確認のうえ利用してください
