# PoENavi v3.3.6 リリースノート

## 依頼書の必要ジョブを検索チップへ表示

- 依頼書の検索時、必要ジョブの種類を検索チップ上で確認できるようにしました
- `Job Lv（欺瞞）：1`のように、ジョブ名と必要レベルをまとめて表示します
- 欺瞞・錠前破り・怪力・工作など、全9種類のハイストジョブに対応しています
- 公式Tradeへ送る検索条件は従来どおり維持されます

## 数値検索チップをマウスホイールで調整

- 数値を編集できる検索チップへマウスカーソルを合わせ、ホイール上下で値を1ずつ増減できるようにしました
- 対象は、リンク数・ilvl・ジェムLv・品質・マップTier・ベース防御値・Area Lv・公開Wing数・Job Lv・クラスタージュエルのパッシブ数です
- 各項目の上限・下限を維持し、空欄では値を変更しません
