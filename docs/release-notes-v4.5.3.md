# PoENavi v4.5.3 リリースノート

## PoE 1 3.30の検索対応を拡充

- 新アイテムクラス「臓器」に対応し、ベース名・部位・上級／低級・暗黙モッドを使って検索できるようにしました
- 未鑑定アイテムのTierを読み取り、検索条件として編集・完全一致検索できるようにしました
- ブライトマップの日本語表記とマップエリアを認識し、正しいマップベースで検索できるようにしました
- シェイパー／エルダーガーディアンマップの固有暗黙モッドを初期状態で検索対象にしました
- 日本語の「鉤爪」と、コラプト済みレアアイテムのベース検索を修正しました
- 新アイテムが見つからない場合に公式Tradeアイテムカタログを再取得するようにしました

## Currency Exchangeの3.30対応

- 「スレッド」カテゴリと10種類のスレッドをレート管理へ追加しました
- 新リーグ開始直後でも、取得可能な市場データからレート候補を作れるようにしました

## タイマーのリセットを修正

- リセット後にReady状態へ移行できないことがある問題を修正しました

## 注意事項

- 本バージョンはコード署名証明書を使用していません
- zipダウンロード時にWindows DefenderやSmartScreenで警告される場合があります。ダウンロード元と公開ハッシュを確認のうえ利用してください
