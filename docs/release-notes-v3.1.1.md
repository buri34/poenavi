# PoENavi v3.1.1 リリースノート

## ぽえとれ検索画面の改善

- 「Mod数値」の許容範囲を変更しても、ユーザーが変更した検索Modのチェック状態を維持
- 数値範囲は手動入力値ではなく、取り込んだ元アイテムの数値から再計算するよう修正
- 完成品装備の検索条件を、主要性能、集約疑似Mod、未集約の特殊Modの順に整理
- 防具は最終AR／EV／ES／Ward、武器はTotal DPS／pDPS／eDPSを優先表示
- 元のPrefix／Suffixとティアを「Mod構成を表示」から確認可能に
- 元素耐性合計を通常表示し、最大の個別元素耐性はAwakened PoE Trade準拠で隠し候補へ移動
- ソケット数を検索条件から除外し、リンク数を編集可能な検索チップへ統合
- 5リンク／6リンクは初期ON、1～4リンクは初期OFFに変更
- 通常表示するMod数に応じて画面を縦へ拡張し、FHDでは価格結果欄の高さを調整してMod欄を優先表示
- 画面内に収まらない場合のみスクロールを使用し、隠し候補・Mod構成・関連品の開閉時も高さを再計算

## ホットキーの安全性改善

- アプリ自身が送信する`Ctrl+C`、`Ctrl+V`、`Ctrl+F`、`Enter`をグローバルホットキー処理から除外
- 任意コマンドへ`Ctrl+C`などを登録した場合に、価格検索やMap Checkから誤発火する問題を修正
- 価格検索、Map Check、チャットコマンドなどのゲーム操作系ホットキーを、PoE 1／2が前面の時だけ有効化
- タイマー開始・停止・ラップ、Cheat Sheets表示切替、クリック透過切替は従来どおりPoE非アクティブ時も利用可能
- `Shift+Space`でぽえとれの最小化ボタンやレート更新ボタンが誤作動しないよう、ヘッダーボタンのキーボードフォーカスを修正

## 修正

- 6リンク条件とソケット数が重複して表示・送信される問題を修正
- Divine／Chaosレートの更新が意図せず実行される問題を修正
