# PoENavi v4.1.3 リリースノート

## ぽえとれ操作モードの単独キーホットキーに対応

- ぽえとれ検索の操作モードで、CtrlやAltを組み合わせない単独キーを設定できるようにしました
- 設定画面の修飾キーで「なし」を選び、F1など任意の対応キーを指定できます
- 従来のAlt/Ctrlを使った設定と、既定のAlt+Dはそのまま利用できます
- AUTO-HIDEのホットキーと動作は変更していません

※単独キーに割り当てると、Path of Exileが前面にある間は同じキー本来の操作より、ぽえとれ検索が優先されます。

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
