# PoENavi v3.2.1 リリースノート

## ぽえとれの価格表示修正

- スカラベをマップフラグメントから専用カテゴリーへ分類し、poe.ninjaのスカラベ参考価格を表示するよう修正
- 日本語版の占いカード名と英語名の対応ずれを修正
- 「最後の仕上げ」を `The Finishing Touch` として正しく検索し、Trade API・poe.ninja価格・リンクへ反映
- 占いカードの日英対応を配列順ではなく、検証済みの識別子対応表から解決する方式へ変更

## 起動時の選択順を改善

- 起動時は先にPoE1 / PoE2を選び、その後に「ぽえなび / ぽえとれ」を選ぶ順番へ変更
- PoE2選択時は、現在PoE1専用のぽえとれを選択できないことが分かる表示へ変更
- 機能ごとのPoE1 / PoE2対応状況を一元管理し、未対応モードからの起動を防止

- 対象コミット: `v3.2.0..v3.2.1`
