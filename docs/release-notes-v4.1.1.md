# PoENavi v4.1.1 リリースノート

## オーバーレイ操作を改善

- クリックスルー設定を、メイン画面だけでなく切り離したパネルにも反映するようにしました
- クリックスルー中に新しく切り離したパネルにも、現在の設定が自動で適用されます

## PoE2版を調整

- ベースアイテム検索でDesecrated（冒涜）Modを初期選択しないようにしました
- Act 3「アザク湿原」のエリアレベルを40へ修正しました

## Windows版のテスト安定性を改善

- Qtテストをファイルごとの独立プロセスで実行し、テスト間の状態干渉によるWindows CIのクラッシュを防ぐようにしました

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
