# PoENavi v3.2.3 リリースノート

## 多重起動を防止

- ぽえなび本体を複数同時に起動できないように変更
- 2回目の起動時は、起動済みの画面を前面に表示
- 「ぽえなびは起動済みです」と案内し、2つ目の本体は起動せず終了
- モード切り替えによる再起動は従来どおり利用可能

## ぽえとれ検索結果ウィンドウの位置を記憶

- タイトルバーを手動でドラッグした場合だけ、移動先を保存
- スタッシュ側とインベントリ側の表示位置を別々に記憶
- PoEウィンドウの移動や解像度変更時も、保存位置を表示範囲内へ自動調整
- ぽえなび・ぽえとれの両設定画面から手動位置をリセット可能

## v3.2.2からの変更範囲

- 対象コミット: `v3.2.2..v3.2.3`
- PoE1モードのぽえとれUIと、Windows起動制御を変更
