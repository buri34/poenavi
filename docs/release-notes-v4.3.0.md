# PoENavi v4.3.0 リリースノート

## アビス冒涜ModのTierチェックを追加

- Reveal画面の3択を読み取り、各ModのTierと数値範囲をゲーム画面上へ表示できるようにしました
- インベントリを開いた状態を優先し、読取に失敗した場合は登録済みの閉じた状態の範囲で再試行します
- 部位によってTierが変わる場合だけ、装備種類を選択できます
- 読取失敗・未対応・Tierなし・部位未選択を区別して表示します
- 画面読み取り機能はエクスペ報酬価格チェックと共有し、初期ショートカットはAlt + Rです

## 読取精度と安全性を改善

- OCR候補が矛盾する場合は推測せず、読取失敗として扱うようにしました
- 極端に細い画像や無関係な画像を3択として誤認しにくくしました
- Alt + Rの連打や古い非同期結果で表示が上書きされないようにしました

## 設定・表示を改善

- インベントリ開／閉の読取範囲と指定例画像を追加しました
- Tier数値範囲表示をデフォルトONにしました
- 通常スタッフとクォータースタッフを分離し、「胴体防具」は「鎧」と表示します
- 現在のPoE2に未実装の武器カテゴリを部位候補から除外しました

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
