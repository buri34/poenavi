# PoENavi v3.2.4 リリースノート

## 海図（Chart）の価格検索に対応

- 砂の海底・サンゴの森・サンゴ礁の海図を解析し、公式Trade検索へ送信
- 海図名の完全一致検索と、同じ海域を対象にした検索を切り替え可能
- エリアレベル、アイテム数量・レアリティ、モンスターパックサイズ、死人の硫黄を検索条件として表示
- 未鑑定の海図にも対応
- 最新Awakened PoE TradeのItem／Statデータを反映

## マップModの認識精度を改善

- 征服者4種の砦Modを、公式Tradeの単一Modとして検索可能に変更
- Uber Map、Nightmare Map、日本語表記差による未認識Modを追加対応
- 確率なしで衰弱を付与するNightmare Map Modを、確率付きModとは別条件として認識
- マップMod管理画面の列順を「危険 → 警告 → 有利」に変更

## 設定画面を調整

- ぽえなび側のAUTO-HIDEキー設定を緑テーマへ統一
- 修飾キーと通常キーの入力欄幅を調整
- 検索結果位置のリセットを、関連するぽえとれ設定側だけに表示

## v3.2.3からの変更範囲

- 対象コミット: `v3.2.3..v3.2.4`
- PoE1モードのぽえとれ検索、マップModチェック、設定画面を更新
