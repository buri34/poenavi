# PoE2版ぽえとれ Windows実機テスト記入ガイド

## 役割分担

鰤さんは、Windows実機で画面に出た一次情報を記録する。正常・不具合の原因判定やModの切り分けは
もじゃこがMac側で行う。必要なケースと証拠は削らず、判断だけを分離する。

## 1ケースの進め方

1. `対象アイテム`を用意し、`操作`を行う。
2. 詳細コピーを`P2-WIN-001-ja.txt`のような名前で保存する。
3. `確認A／B／C`を画面と見比べ、それぞれの結果を記入する。
4. 検索し、件数・価格表示・URLを記入する。
5. 差分があれば画像を保存し、見えた事実だけを一言書く。

## 記入欄の選択肢

- `A結果／B結果／C結果`: `一致`／`差分あり`／`確認不能`
- `検索応答`: `結果あり`／`0件`／`通信エラー`／`未検索`
- `価格表示`: `正常`／`表示なし`／`不自然`／`対象外`／`未確認`
- `総合結果`: `OK`／`差分あり`／`実施不能`／`未実施`

自由記述が必要なのは、原則として`見えた差分・メモ`だけ。原因の推測は不要。

## 検索0件の扱い

0件は、正常な「出品なし」と検索条件の不具合の両方があり得るため、その場では合否を決めない。
次を記録すれば、そのケースの実機作業は完了とする。

- `検索応答=0件`
- `表示件数=0`
- 生成された公式Trade URL
- 使用した詳細コピーの保存名
- 検索条件が画面上で期待と違えば、その差分と画像名

この材料から、もじゃこが出品有無、最終Trade2 JSON、各Modを外した比較検索を行う。

## 詳細コピー

- 通常ケース: 使用した現物の日本語詳細コピーを保存する。
- `P2-WIN-057`: 同じ現物の日本語・英語を両方保存する。
- `詳細コピー要件=収集済みfixture`: 新規保存は不要。
- 差分が日本語固有か疑われる場合は、後から同じ現物の英語版を追加で依頼する。

詳細コピーはCSVセルへ全文を貼らず、専用フォルダへ`.txt`で保存し、CSVにはファイル名だけ記入する。

## P2-WIN-001の記入例

Rare Spearを検索して、識別とチップは期待どおり、公式Tradeが0件だった場合:

- A結果: `一致`
- B結果: `一致`
- C結果: `一致`
- 詳細コピー保存名: `P2-WIN-001-ja.txt`
- 検索応答: `0件`
- 表示件数: `0`
- 価格表示: `表示なし`
- 公式Trade URL: 生成されたURL
- 総合結果: `OK`
- メモ: 空欄でよい

`OK`は「出品が存在した」という意味ではなく、「期待したUI・検索条件で検索処理が完了し、一次情報を
記録できた」という意味。0件の妥当性はMac側の分析で確定する。
