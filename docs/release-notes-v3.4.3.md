# PoENavi v3.4.3 リリースノート

## 新しいキャラクター開始時のガイド進行リセットを改善

- PoENaviを起動していない間に新しいキャラクターを開始した場合、次回起動時にClient.txtの履歴から検知してガイド進行のリセットを確認するようにしました
- PoE 1では「黄昏の岸辺 → Lv2」、PoE 2では「川岸」への入場を新しいキャラクター開始の判定に使用します
- PoE 2でもエリア訪問回数と直前の訪問状態を保存し、再起動後に正しく引き継ぐようにしました
- PoE 2で新しいキャラクターを開始した際、進行フラグと一緒にエリア訪問状態もリセットするようにしました
