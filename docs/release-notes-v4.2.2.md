# PoENavi v4.2.2 リリースノート

## ぽえとれの検索を改善

- PoE2の通貨形式へ「カオスオーブのみ」を追加しました
- PoE2のタイムレスジュエルで、Seed値を完全一致検索できるようにしました
- 「英雄の悲劇」と「不死の憎しみ」の人物別Modを正しく検索できるようにしました
- Trade APIが一時的に応答しない場合、接続を作り直して1回だけ自動再試行するようにしました
- アイテムを取り込めなかった際の通知音を設定で切り替えられるようにし、初期状態をOFFにしました

## みになびの前面表示を改善

- 前面表示を「PoEがアクティブな時だけ」「常に最前面」「最前面にしない」から選べるようにしました
- 初期設定を「PoEがアクティブな時だけ最前面」に変更しました
- PoEと他のウィンドウを切り替えた際、みになびと鍵ボタンが正しく前後へ移動するようにしました

## Windowsログイン時の自動起動を追加

- ぽえとれ設定から、Windowsログイン時にぽえとれを直接起動できるようにしました
- ZIPの配置場所を移動した場合、次回起動時に自動起動先を新しい場所へ更新します

## 設定画面を改善

- ぽえとれ設定とエクスペディション報酬設定のチェックボックスを、見やすい青色のデザインへ統一しました
- 起動設定の補足文と項目配置を整理しました

※Windowsログイン時の自動起動、アイテム取込失敗時の通知、エクスペディション報酬価格チェックは初期状態では無効です。

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
