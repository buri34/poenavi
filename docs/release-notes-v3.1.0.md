# PoENavi v3.1.0 リリースノート草案

> 公開前の草案です。GitHub Release作成時の本文として使用し、Windows実機・配布ZIP確認後に最終確定します。

## 主な新機能

### Map Check

- Map系アイテムへカーソルを合わせてホットキーを押すと、Modを危険・警告・有利に色分けして表示
- 非ユニークMap、Invitation、Heist Contract／Blueprint、Expedition Logbookに対応
- 3つのプロファイルへ、ビルドごとに異なるModラベルを保存可能
- Modの検索、設定済み絞り込み、限定カテゴリ表示、未確認Mod管理に対応
- Mod数や複数行表示に合わせて画面の高さを自動調整し、画面内に収まる場合は全Modをスクロールなしで表示
- 検索結果画面のフォントサイズ設定（小／中／大）をMap Checkにも反映
- 3.29で廃止されたプレイヤー反射Modに代わり、レアモンスターの物理／元素の棘を初期危険Modに設定
- 画面はマウスカーソル付近へ表示し、モニター外へ出る場合は作業領域内へ自動補正
- 日本語クライアントで報告されたMap Modの表記揺れを追加認識

### 任意チャットコマンド

- 設定画面の「基本設定」右に「任意コマンド設定」タブを追加
- 名前、ホットキー、`/`で始まるPoEチャットコマンド、有効／無効を自由に登録
- ぽえなび／ぽえとれの両モードで共通利用可能
- ホットキー欄をクリックして、実際に押したキーまたは複合キーを登録
- 既存機能を含むホットキー重複チェックに対応

### ぽえとれのタスクトレイ常駐

- ぽえとれモードで最小化したとき、Windowsの通知領域へ格納
- トレイメニューから「ぽえとれを表示」「設定」「終了」を実行可能
- トレイアイコンのクリック／ダブルクリックで復帰
- 通知領域が利用できない環境では通常の最小化へフォールバック

## ぽえとれ検索の改善

- ヴァールスキルジェムのコピー内容からVaal版を判定し、日本語のヴァールジェム名で検索・表示
- 透視のオーブの「マップエリア」を読み取り、`透視のオーブ (岸辺)`のようにエリア別アイテムとして検索・表示
- ぽえとれ側のホットキー設定を、クリック後に実際のキー入力を受け付ける方式へ統一
- Awakened PoE Trade v3.29.103相当のStat、Gem、Unique固定Mod、関連ドロップ定義へ更新
- 新しい装備Mod・サポートスキル組み合わせ315件を、公式日本語Trade APIと照合して台帳へ追加
- Standardの完成品検索ではSplit品を含め、ベースアイテム検索では非Splitへ限定するようAwakened準拠に変更
- Awakened準拠の関連アイテム定義を更新し、現行版Doryani's Delusionのベースを旧世代品へ誤接続しないよう修正

## ウィンドウ・設定画面の改善

- 切り離しウィンドウの操作ヘッダーが画面外へ出た場合、接続中モニターの作業領域内へ自動補正
- マップ画像の拡大ウィンドウも、解像度差や負のモニター座標を含めて作業領域内へ自動補正
- 任意コマンド設定を、ぽえなびは緑、ぽえとれは紫のテーマに統一
- 任意コマンド一覧の行高、不要な行番号領域、文字切れを修正
- 「検索結果画面」の設定見出しを「検索結果・マップチェック画面」へ変更
- 「修道院へ移動」から仮表記を削除
- PoEクライアント側と重複した「隠れ家へ移動」固定ホットキーをぽえなびから削除
- ぽえなび／ぽえとれのヘッダーボタンを、各テーマカラーに合わせた専用アイコンへ統一

## 自動アップデートの改善

- 前回更新の`PoENavi.backup`が残っていても、正常なバックアップなら日時付きで安全に退避して更新を継続
- 更新成功時は古い退避バックアップを整理し、失敗時は更新前の状態へ復元
- 不正なバックアップ、更新失敗フォルダ、OneDriveやセキュリティソフトによるファイルロックを検知した場合は、ファイルを削除せず安全に停止
- エラー原因ごとに、ユーザーが行う具体的な復旧手順を番号付きで表示

## 修正

- Map Checkで一部の日本語Map Modが未認識になる問題を修正
- 欠落していたAct 10「聖廟」のエリア枠と専用ガイドを追加し、Act 5の同名ガイドが表示される問題を修正
- Map用ではないStatがMap Mod台帳へ混入する問題を修正
- 未確認Mod表示が無効なとき、用途のない確認列が残る問題を修正
- 色設定済みModを誤操作で解除しやすい問題を修正
- Mod数が多いと不要なスクロール操作が発生する問題を修正
