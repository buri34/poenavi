# PoENavi v4.5.6 リリースノート

## 複数モニター環境のウィンドウ移動と起動復旧を改善

- Windows／Qt標準のウィンドウ移動処理を使用し、解像度や表示倍率が異なるモニター間の移動を安定化しました
- 保存済みの位置やサイズが画面外・モニター間の空白にある場合、起動時に表示可能な範囲へ補正するようにしました
- 切断済みモニターなどの異常な位置情報は既定位置へ戻し、同じ場所でクラッシュを繰り返す状態から復旧しやすくしました

## 起動時のウィンドウ位置初期化設定を追加

- 基本設定へ「起動時にウィンドウ位置を毎回初期化する」を追加しました
- ONにすると保存済みのウィンドウサイズを維持し、選択したモニターの右上へ毎回配置します
- 保存済みサイズが画面より大きい場合だけ、表示可能な範囲へ縮小します

## 注意事項

- 本バージョンはコード署名証明書を使用していません
- zipダウンロード時にWindows DefenderやSmartScreenで警告される場合があります。ダウンロード元と公開ハッシュを確認のうえ利用してください
