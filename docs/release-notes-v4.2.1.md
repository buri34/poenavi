# PoENavi v4.2.1 リリースノート

## エクスペディション報酬価格チェックの表示を改善

- 読取範囲を指定するガイドと、指定例画像の案内を見やすくしました
- エクスペディションをイメージした渦紋章へボタンアイコンを変更しました
- 「ランダムなカレンシー 5個」では、価格の代わりに特別メッセージをランダム表示するようにしました

※エクスペディション報酬価格チェックは初期状態では無効です。PoE2版ぽえとれ上部の専用ボタンから設定してください。

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
