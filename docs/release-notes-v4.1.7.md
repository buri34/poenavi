# PoENavi v4.1.7 リリースノート

## Cheat Sheetの透明率設定を改善

- 登録画像と背景の透明率を別々に調整できるようにしました
- 表記を「画像の透明率」「背景の透明率」に統一しました
- 初期値を画像100%、背景0%にしました
- 背景の透明率が実際の表示へ反映されない問題を修正しました

## ぽえとれのPoE2検索を改善

- ジクアニの照準のソウルコアを、装備への仮挿入検索に追加しました

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
