# ［内部コンポーネント］PoENavi 高精度OCRパック 1.3.1-r1

**これはPoENavi本体ではありません。通常はPoENaviが自動取得するため、手動ダウンロードは不要です。**

PoE2「アビス冒涜Modティアチェック」で、通常のWindows OCRが数値だけを読み取れなかった場合に使用する
高精度OCRパックです。

このパックには次が含まれます。

- NDLOCR-Lite 1.3.1を利用する自己完結ヘルパー
- CPUランタイム
- 学習済みONNXモデル4本
- NDLOCR-Liteおよび依存関係のライセンス

PoENaviはSHA-256とZIPの安全性を検証してから、ユーザーデータ領域へ自動導入します。
OCR画像と認識文字列はPC内で処理し、外部サービスへ送信しません。
