# PoENavi v4.1.6 リリースノート

## ぽえとれのPoE2検索を改善

- 最新のソウルコア17種を追加し、既存ソウルコアの効果と数値を更新しました
- マジック装備で、アイテムレベルにかかわらず「完成品／ベースアイテム」を切り替えられるようにしました
- 現在のレアリティ検索条件を表示し、ベース検索では「マジック完全一致／非ユニーク」を選択できるようにしました
- 取引方式と通貨の選択をPoE1／PoE2別に保存し、別アイテムの検索時や再起動後も維持するようにしました
- OBS配信モードの待機中タイトルバーに、透過率設定を追加しました
- 一部のフラスコ、ジュエル、装備、ジェムで発生していたメタデータ未解決や検索条件の誤りを修正しました
- 鐘鳴のスタッフでは、シギルオブパワーのスキルレベルを検索Modとして表示するようにしました

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
