# PoENavi v3.3.5 リリースノート

## ぽえとれの検索ホットキーを安定化

- Windowsでは、操作モードの検索ホットキーをWin32の低レベルキーボードフックで処理するよう変更しました
- PoEが前面の時は検索ホットキーをゲーム側へ通さず、同じキーへ割り当てたスキルなどの誤動作を防ぎます
- PoEやぽえとれ以外の画面では、同じキー操作を通常どおり利用できます
- 操作モードのホットキーは、AUTO-HIDEと同様に`Ctrl`または`Alt`と通常キーの組み合わせから設定します。初期設定は引き続き`Alt+D`です

> 他の常駐アプリが同じグローバルホットキーを使用している場合、競合する可能性があります。反応しない場合は、どちらかのアプリで割り当てを変更してください。

## 検索結果画面からの連続検索

- 検索結果を表示したまま別のアイテムへカーソルを移し、再度検索ホットキーを押すと、PoEを自動的に前面化して次の検索を行えるようにしました
- 検索結果ウィンドウのWindowsハンドルを表示のたびに更新し、連続検索を繰り返しても正しく認識します

## 検索条件と画面表示の修正

- 「ドッペルゲンガーの装い」の、正気状態で受ける物理・混沌ダメージが低下するModを正式なTrade検索条件として解決できるようにしました
- 「ネビュリス」など検索Modが多いアイテムで、Mod一覧と下部の操作欄が重なる問題を修正しました
- 通常は従来どおりModを全行表示し、画面内へ収まらない場合だけMod一覧をスクロール表示します

## 内部変更

- 検索ホットキーの条件付き抑止では`keyboard`ライブラリを使用しない構成へ変更しました
- Win32フックの受信、画面判定、検索処理への受け渡しを診断ログへ記録します
