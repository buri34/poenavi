# PoENavi v4.5.7 リリースノート

## PoE 1「ぽえとれ」の検索対象を更新

- アッツォアトルの寺院部屋を価値に応じて整理し、主要な高価値部屋を初期選択するようにしました
- 「原初の高貴なオーブ」と「オリジネーターの高貴なオーブ」をカレンシー交換へ追加しました
- 物理ダメージ主体のワンドで物理DPSを検索条件として利用できるようにしました
- 新しいマップModとアイテム状態の解析へ対応しました

## 高精度OCRと未鑑定ユニーク検索を改善

- ハイスト報酬の高精度OCRをあらかじめ起動して待機させる設定を追加しました
- 高精度OCRを必要時だけ起動する場合との、速度とメモリ使用量の違いを設定画面へ明記しました
- 未鑑定ユニークの候補画像を必要な分だけ読み込むようにし、候補が多い検索の負荷を軽減しました

## 通知・タイマー・更新処理の安定性を改善

- ローグハーバー滞在中も隠れ家滞在通知の対象にしました
- Expedition OCRの古い読み取り結果が後から画面へ反映されないようにしました
- タイマー状態を安全に保存し、書き込み中断や時刻変更の影響を受けにくくしました
- 設定ファイル破損から自動復旧した際に、一度だけ利用者へ通知するようにしました
- 更新確認と公式Divineレート取得が待機状態のまま止まらないようにしました

## 注意事項

- 本バージョンはコード署名証明書を使用していません
- zipダウンロード時にWindows DefenderやSmartScreenで警告される場合があります。ダウンロード元と公開ハッシュを確認のうえ利用してください
