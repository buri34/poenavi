# PoENavi v3.3.8 リリースノート

## ぽえとれのホットキー入力を改善

- マウス設定ソフトから割り当てたAltキーとキーボードのDキーを組み合わせても、操作モードの検索を開始できるようにしました
- PoENavi自身が送信するコピー操作などは、引き続きホットキーとして誤認しないよう除外します
- 検索結果の外側をクリックしても画面が閉じず、表示されたままになることがある問題を修正しました

## クラスタージュエル検索を修正

- ノーマル品を含むクラフト可能なアイテムの検索で、フラクチャー品を自動的に除外するようAwakened PoE Trade準拠へ修正しました
- ベースアイテム検索で、クラスタージュエルの基礎効果に含まれる固定数値を最小値として誤送信し、結果が0件になる問題を修正しました
- クラスタージュエルの追加パッシブ数には「Mod数値の許容率」を適用せず、完成品とベースアイテムで同じ専用条件を使用するようにしました

## タイムレスジュエル検索を修正

- 日本語の詳細コピーに含まれる人物名とシード値を、人物別の公式Trade条件へ解決できるようにしました
- 上品な慢心、致命的な誇り、残忍な自制、栄光ある虚栄、献身的な信仰など、Awakened PoE Tradeが対応する全人物を一括対応しました
- タイムレスジュエルのシード値は「Mod数値の許容率」を適用せず、常に完全一致で検索します
- 対応済みのタイムレスジュエルで「メタデータ未解決」と表示される問題を修正しました
