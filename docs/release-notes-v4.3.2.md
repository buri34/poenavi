# PoENavi v4.3.2 リリースノート

## アビス冒涜Modチェックの精度を改善

- 3つのOCR候補のうち、同じMod・数値・Tierが2件以上一致した場合に結果を採用するよう改善しました
- 回避力などの短いModで起こる1文字のOCR誤読を、安全に候補が1つへ絞れる場合だけ救済します
- 同じ数値がプレフィックスとサフィックスの両方に存在するModは、それぞれのTierと数値範囲を結果欄へ併記します
- 複数Tierへ該当する場合や、一部のModだけ未対応の場合も、判定できた結果を維持します

## エクスペ・アビスの画面読取を共通化

- エクスペ報酬チェックとアビス冒涜Modチェックで、共通の画面読取ショートカットを使用するようにしました
- 画面を軽量判定し、該当する機能だけOCRを実行します
- Ctrl／Alt／Shiftを組み合わせたショートカットへ対応しました
- エクスペ画面の誤判定を減らすため、報酬カードの形状判定を改善しました

## PoE2の検索条件を改善

- チャームスロット数など、割合で緩めるべきでない値を固定するよう調整しました
- 完全ロール、比較不能な数値、石板のベース検索、反転Statなどの検索範囲をExiled Exchange 2相当へ調整しました
- ベース／Exact検索の許容率を2%へ制限する仕様は採用せず、従来の設定値を維持します

## 安全性と更新運用を文書化

- OCRは手動ホットキーでのみ開始し、画像とOCR本文を外部送信せず、ゲームを自動操作しないことをREADMEへ日英で明記しました
- 新リーグでアビス冒涜Modデータを更新する際の情報源、非破壊監査、実画面確認の手順を整備しました

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
