# PoENavi v4.5.5 リリースノート

## PoE 1 3.30のBestiary Thread価格に対応

- Currency Exchangeに追加されたBestiary Threadの価格を、ぽえとれで取得できるようにしました
- 関連アイテムの名称変更を現行データへ更新しました

## アッツォアトルの歴史書の部屋検索を改善

- 現在の日本語名「アッツォアトルの歴史書」を認識し、記載された部屋を検索条件へ表示するようにしました
- 「開放された部屋」「塞がれた部屋」の区分にかかわらず、すべての部屋を選択して検索できます
- 高価値の部屋は初期状態で選択し、その他の部屋も必要に応じて選べます
- ゲーム内とトレードサイトで日本語名が異なる部屋を補正し、全86種類の部屋を正しい検索条件へ対応させました

## 注意事項

- 本バージョンはコード署名証明書を使用していません
- zipダウンロード時にWindows DefenderやSmartScreenで警告される場合があります。ダウンロード元と公開ハッシュを確認のうえ利用してください
