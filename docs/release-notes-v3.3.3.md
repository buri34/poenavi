# PoENavi v3.3.3 リリースノート

## ぽえとれをOBSのウィンドウキャプチャに対応

- OBSが認識できる専用の検索結果ウィンドウを追加
- 待機中はドラッグ可能な細いタイトルバーだけを表示し、検索完了時に同じウィンドウの下へ結果を展開
- `Esc`、画面外クリック、閉じるボタンで待機状態へ戻る動作に対応
- 検索処理、公式Trade API、poe.ninja、キャッシュは通常モードと共通化し、二重検索を防止

## 出品結果と検索条件の表示を改善

- 出品価格のChaos Orb／Divine Orb表記を通貨アイコンへ変更
- 4桁価格も表示しやすいよう価格列を拡張
- 未鑑定、Veiled、Foil Unique、Mirrored、Splitの状態条件を通常検索チップと同じ見た目・高さへ統一
- 状態チップのラベルを検索条件の意味が伝わる表現へ改善

## 公式Trade検索を改善

- 公式Trade APIのSeller Collapseを有効化し、同一Sellerの大量出品を検索段階で集約
- 既存のローカル集約も例外的な重複への保険として維持

## ドキュメント

- ぽえなび／ぽえとれのnote記事用Markdown下書きを追加
- OBS配信用検索結果ウィンドウの設計資料を追加

## v3.3.2からの変更範囲

- 対象コミット: `v3.3.2..v3.3.3`
- PoE1モードのぽえとれUI、検索JSON、設定、ドキュメントを更新
