# PoENavi v4.1.0 リリースノート

## PoE2版ぽえとれを正式公開

- PoE2日本語版のアイテムコピーを解析し、公式Trade2とpoe.ninjaを使って価格検索できるようになりました
- レア／ユニーク装備、カレンシー、ジェム、Waystone、タブレット、フラスコ、チャーム、レリック、ログブックなど、PoE2固有カテゴリへ対応しました
- 完成品検索とベースアイテム検索を切り替えられます
- Rune／Soul Core構成、関連アイテム、武器DPS、防御値、耐性・ライフ等の合算条件を検索画面へ反映します
- Fractured／Desecrated／Crafted／EnchantなどModの生成元とTierを表示します
- PoE2の関連アイテム名と検索条件を日本語版へ対応しました

## 検索条件と操作性を改善

- PoE2レア装備は、ホットキー直後に通信せず、条件を確認してから検索する方式にしました
- 検索ボタンのクリックとマウスオーバーのどちらからでも検索できます
- 新しいアイテムを取得した時に前回の検索結果を消し、別アイテムの結果との誤認を防ぎます
- T1／T2 Modを見分けやすくし、重要なT1スピリットとT1スキルレベルを初期選択します
- 不要な条件を隠し候補へ整理し、隠し候補がない場合は切替ボタンを表示しないようにしました
- Mod種別列の幅を抑え、検索Mod本文を読みやすくしました

## PoE2 Trade APIへの対応を強化

- Trade APIのレート制限情報を読み取り、待機時間を画面へ表示します
- 429応答時の不要な再通信を抑え、時間経過後に検索を再開できるようにしました
- 検索結果の段階取得、出品の集約、インスタント取引表示など既存のぽえとれ機能をPoE2へ接続しました

## 設定と安定性を改善

- PoE1 / PoE2を設定画面で変更した場合、内部状態の混在を防ぐため再起動を案内します
- PoE2で利用できないPoE1専用機能を非表示または無効化しました
- PoE2の日本語コピー、検索条件、UI状態を対象とした回帰テストを拡充しました

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
