# PoENavi v4.3.1 リリースノート

## アビス冒涜Modチェックの速度を改善

- Tierデータの照合方式を見直し、結果表示までの待ち時間を大幅に短縮しました
- 同じOCR候補の再計算を避け、画像前処理も高速化しました
- 読取結果が十分な場合は、不要な閉範囲での再読取を省略します

## Tier判定と読取精度を改善

- 同じ数値が複数Tierへ該当する場合に、`T7/T8`のように候補を表示します
- 1つのModが未対応でも、正常に判定できた他のModのTier表示を維持します
- 3つのModから装備種類を絞り込み、矛盾する場合は安全に再読取するようにしました
- 固定数字を含むMod、日本語の増加／減少表記、短いMod文面のOCR誤読へ対応しました

## 設定画面を整理

- アビス冒涜Modチェックとエクスペ報酬チェックの設定を、基本設定・読取範囲などの区分で整理しました
- 指定例を対応する読取範囲の中へまとめ、設定内容を追いやすくしました

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
