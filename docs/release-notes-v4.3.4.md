# PoENavi v4.3.4 リリースノート

## PoE2のRune／Soul Core検索を拡充

- Exiled Exchange 2の更新を確認し、未収録だったLegacy系オーグメント、Stat、アイテム名を追加しました
- Talismanを含む対応装備で、新しいLegacy系オーグメントを仮挿入して検索できます
- Legacy系は1キャラクターにつき1個という制限を、候補表示とTrade検索条件の両方へ反映しました
- 複数効果を持つLegacy系オーグメントも、各効果と値を正しい組み合わせで検索します

## オーグメントの参考価格を表示

- 仮挿入したRune／Soul Coreの参考費用を、検索結果一覧の下へ表示します
- 装着済みオーグメントを安全に特定できる場合、抽出費用を差し引いた回収参考価値と出品最安を比較します
- 回収参考価値が出品最安を上回る場合は、オーグメント抽出に価値がある可能性を控えめに案内します
- 参考価格を取得できない場合や素材構成が曖昧な場合は、誤った金額を表示しません

## PoE2レア装備の再検索を修正

- 同じレア装備を再度コピーした場合も、検索ボタンへのマウスオーバーで再検索できるよう修正しました
- 検索後も選択中の仮挿入素材と個数を保持し、参考費用へ正しく反映します
- 別の装備を新しくコピーした場合は、従来どおり「仮挿入しない」へ戻ります

## PoE1の価格・Trade検索を更新

- 現行の公式TradeデータとAwakened PoE Tradeの確認済み変更を反映しました
- 通常Mapの数量・レアリティ・パックサイズやMap Mod検索条件を修正しました
- Catalystで補正されたMod値、複合防御を持つUnique、防御値の品質補正表示を改善しました
- Corpseのpoe.ninja参考価格と、Unique装備の解呪ダスト推定量を表示します
- 未鑑定Uniqueでは選択した候補に応じて解呪ダスト推定量を再計算します

## 更新データの安全性を強化

- PoE2の公式TradeデータとEE2由来データは、生成元・日英対応・差分を検証してから更新するようにしました
- 未確認の削除や翻訳変更、生成元revisionの不一致がある場合は、既存データを維持して更新を停止します

※表示価格と回収価値はpoe.ninja等の参考情報による目安であり、実際の取引価格や利益を保証するものではありません。

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
