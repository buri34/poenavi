# PoENavi v4.2.0 リリースノート

## エクスペディション報酬価格チェックを追加

- ルーンシェイプ報酬を読み取り、poe.ninjaの相場を高貴なオーブ換算で表示できるようにしました
- 専用設定画面から、環境に合わせた読取範囲とショートカットを設定できます
- ルーン1～10個、1段・2段表示、画面下まで並ぶ報酬へ対応しました
- 読取範囲の指定例を、サムネイルから拡大して確認できます
- 読取ショートカットは既定のAlt+Eに加え、Ctrl／Altなしの単独キーも設定できます

## ぽえとれのPoE2検索を改善

- 一部の特殊なアミュレットで、付与されたスキルを検索条件として表示するようにしました

※エクスペディション報酬価格チェックは初期状態では無効です。PoE2版ぽえとれ上部の専用ボタンから設定してください。

※zipダウンロードの際、Windows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。ダウンロード元と公開ハッシュを確認のうえ利用してください。
