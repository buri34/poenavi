# PoENavi v4.5.0 Pre-Release リリースノート

> **このバージョンは先行テスト用のPre-Releaseです。**
> PoE1ハイスト報酬チェックを中心に実機検証が十分ではないため、通常版ではなく人柱版として公開します。不具合や認識失敗が見つかった場合は、可能であれば対象画面の画像と状況を添えて報告してください。

## PoE1 ハイスト報酬価格チェック

- PoE1のGrand Heist展示品を、手動範囲指定とOCRで読み取り、既存のぽえとれ価格検索へ渡せるようになりました
- PoE1メイン画面へハイスト設定ボタンを追加しました
- 「ハイスト報酬OCRを有効化」した時だけOCRとホットキーを有効にします
- 既定ホットキーは`Alt+E`です。PoE2のエクスペ報酬チェックと同じキーを使用できます
- 報酬名から青いMod末尾までドラッグすると、マウスを離した時点で読み取りを開始します
- レプリカユニーク、置換ユニーク、実験的ベース、カレンシー、スカラベ、盗賊のトリンケットに対応しました
- レプリカ92件・置換ユニーク9件では、利用可能な固定Mod候補を数値空欄・初期OFFで検索条件一覧へ表示します
- 盗賊のトリンケットでは、現行39種類のMod文章と数値を読み取り、Tier範囲を検証してから数値入り・初期OFFで表示します
- 紛らわしいトリンケットModは高精度OCRとの一致時だけ採用し、誤確定より条件を表示しないことを優先します
- 実験的ベースでは、必要に応じてアイテムレベルを手入力できます

## ハイストでも高精度OCRを利用可能

- ハイスト設定画面に、アビスと共通の高精度OCRパック管理欄を追加しました
- 未導入または旧版の場合は、設定画面から取得状況・進捗・エラー・再試行を確認できます
- OCRパックはアビスと共通で、二重にダウンロードしません
- 高精度OCRは必要な時だけ起動し、最後に使用してから3分で自動終了します
- OCR画像と認識文字列はPC内で処理し、外部サービスへ送信しません

## 価格表示・交換レートの改善

- ぽえとれの価格参照を公式Currency Exchange中心へ移行しました
- PoE1・PoE2のCurrency Exchange対象カタログを追加しました
- 任意の交換レートを最大10件までメイン画面へ表示できるようになりました
- 通貨ペアの選択、双方向レート表示、ドラッグ並べ替え、アイコン取得に対応しました
- PoE2ユニーク価格は、安価な場合はExalted、高額な場合はDivineで表示します

## 隠れ家滞在通知

- 集中モード中、隠れ家に設定時間滞在した時に音声で通知できるようになりました
- PoE1・PoE2ごとにClient.txtを設定し、エリア移動を自動検出します
- 標準通知音5種類と任意のWAV／MP3を利用でき、設定画面から試聴できます
- 経過時間と通知状態をメイン画面へ表示します

## PoE2 Act 4・みになび

- Act 4攻略チェックリストオーバーレイを追加しました
- Plunder's Pointなど新エリアへ対応しました
- PoE2みになび編集ボタンと更新済みガイド内容を追加しました
- フォントサイズ、自動フェード、チェック表示の連動を改善しました

## UI・操作性

- ぽえとれヘッダーへ現在のPoE1／PoE2モードを表示します
- ぽえなび・ぽえとれの設定／管理画面のデザインを統一しました
- 前回選んだ検索条件を保持する設定を追加しました
- PoE1／PoE2のCurrency Exchangeカテゴリと一部アイコンを整理しました

## 注意事項

- ハイスト報酬チェックは手動範囲指定専用です。展示パネルの自動検出は使用しません
- ランダムなヴェールMod構成を持つReplica Paradoxicaでは、名前だけから固定Mod候補を表示しません
- トリンケットMod OCRは実画像2件・異なる5 Modで回帰確認していますが、全39種類を実画像検証したものではありません
- zipダウンロード時にWindows Defenderで誤検知される場合があります。PoENaviは現在コード署名証明書を使用していません。公開ハッシュを確認のうえ利用してください
