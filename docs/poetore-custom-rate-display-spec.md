# ぽえとれ 任意レート表示 仕様

更新日: 2026-09-28
状態: 仕様確定・工程1〜7実装済み・Windows実機確認待ち
対象: ぽえとれメイン画面の既存`Divine / Chaos|Exalted 換算`カード

## 目的

メイン画面の固定1ペア換算カードを、ユーザーが選んだ最大10件のCurrency Exchange直接レートを一覧表示できる領域へ置き換える。

検索ウィンドウ上部の換算ボタンは今回の対象外とする。

## 基本仕様

- PoE 1とPoE 2で登録内容を分離する。
- 各PoE版で最大10ペアを登録できる。
- 同じPoE版ではリーグを変更しても登録内容と表示順を共有し、価格だけを再判定する。
- 価格は選択した2品間の直接取引だけから求める。
- 別通貨を介したクロス換算は行わない。
- 左右が同じ品のペアと、同じ向きの重複ペアは登録できない。
- 左右逆のペアは別レートとして登録できる。

## 初期状態と保存

- 新しい設定キーが存在しない初回だけ、次を1件登録する。
  - PoE 1: Divine Orb → Chaos Orb
  - PoE 2: Divine Orb → Exalted Orb
- デフォルトペアも通常行として削除できる。
- 0件は有効な保存状態とし、再起動後にデフォルトを復活させない。
- 登録ペア、表示順、0件状態、初回登録済み状態をPoE 1／PoE 2別に保存する。
- 追加、上下移動、削除は操作ごとに即時保存し、メイン画面へ即時反映する。
- 管理画面に`保存`／`キャンセル`ボタンは置かない。

## メイン画面

### レート行

表示例:

```text
[アイコン] 神のオーブ 1 ＝ 174 [アイコン] カオスオーブ [ゴミ箱]
```

- 全行の右端にゴミ箱アイコンを置く。
- ゴミ箱は確認ダイアログなしで即時削除する。
- 日本語名が収まらない場合は省略表示し、ツールチップで全文を表示する。
- 更新時刻、取得状態、公式データ説明はカード下部へまとめ、各行へ繰り返さない。

### 件数ごとの表示

- 0件: コンパクトな領域の中央に薄い`＋`だけを表示する。
- 1～9件: 全レート行の下に薄い`＋`を表示する。
- 10件: 全10行を表示し、`＋`を非表示にする。
- 横幅は現状を維持し、カードとメイン画面を登録件数に応じて縦へ自動拡張する。
- 最大10行をスクロールなしで表示する。
- PoE 1／PoE 2切替時は、それぞれの登録件数に合わせて高さを調整する。
- 画面下端からはみ出す場合だけ、ウィンドウ位置を画面内へ補正する。

## 数値表示

- 左側1単位あたりの右側数量を表示する。
- 内部価格は元の精度を保持し、画面表示だけ最大4桁の有効数字へ通常の四捨五入を行う。
- 先頭の0は有効数字へ数えない。
- 丸め後、小数点以下の右端に続く不要な0を省略する。
- 整数部分の0と、小数点位置を表すために必要な0は残す。

例:

- `174.36` → `174.4`
- `12.345` → `12.35`
- `1.2345` → `1.235`
- `0.005735260...` → `0.005735`
- `12.50` → `12.5`
- `0.2500` → `0.25`

## 価格判定と状態表示

- 直近24時間に有効な直接約定がある場合だけレートを表示する。
- 直接約定がない場合は`取引データなし`と表示する。
- 取引はあるが異常値判定で保留した場合は`価格未確定`と表示する。
- 注文板だけ存在し、両側の実取引量がない市場は価格根拠にしない。
- 登録後に取引が生まれる可能性があるため、`取引データなし`のペアも登録を維持する。
- 候補一覧から一時的に消えた登録済みペアを自動削除しない。

### 起動直後と通信失敗

- 起動直後は、24時間以内の保存済み前回確定値を即時表示する。
- バックグラウンド確認中はカード下部に`最新データを確認中…`と表示する。
- 新しい公式データの取得成功後、表示を更新する。
- 取得失敗時、前回確定値が24時間以内なら値を残し、`最終確認 ○時間前`と表示する。
- 前回確定値が24時間を超える場合、またはキャッシュがない場合は値を表示せず、`最新データを取得できません`と表示する。
- 通信失敗と、正常取得の結果として直接取引がない状態を区別する。

## 公式データの更新説明

表示文言:

```text
公式取引データ（1時間単位・自動取得）
```

ツールチップ:

> 公式Currency Exchange APIは、完了した1時間ごとの取引データを提供する仕様です。ぽえとれは新しい時間データの公開を自動確認します。

- 起動時に即時確認する。
- 内部では定期的に新しい完了時間の有無を確認し、新時間がある場合だけAPIを取得する。
- 取得失敗時は次の確認で再試行する。
- 手動ボタンの名称は`最新データ確認`とする。
- 新時間あり: `最新の公式データへ更新しました`
- 新時間なし: `新しい公式データはまだありません`
- 取得失敗: `公式データを取得できませんでした`

## 管理画面

画面名は`レート表示の管理`とし、次の領域を同じ画面へ配置する。

```text
レート表示の管理（3 / 10）

登録済み
[↑][↓] 神のオーブ → カオスオーブ       [削除]
[↑][↓] 憤怒のエッセンス → 神のオーブ   [削除]

検索：[__________________]

[カテゴリ] │ [アイコン＋候補一覧] │ 基準通貨
 すべて    │ 選択中のアイテム     │ ○ 神のオーブ
 カレンシー│ …                    │ ○ カオスオーブ
 エッセンス│ …                    │ ○ 高貴なオーブ

                   [追加]
```

- 上部に登録済み一覧を置く。
- 登録済み行には上下ボタンと削除ボタンを置く。
- 先頭の上ボタン、末尾の下ボタンを無効化する。
- 候補一覧だけ縦スクロールできる。
- 右側はDivine／Chaos／Exaltedのラジオボタンから1つ選ぶ。
- 左右を選択すると、追加ボタン付近にペアをプレビューする。
- 両側の選択が有効な場合だけ追加ボタンを有効化する。
- 追加後は左右の選択だけ解除し、管理画面を開いたままにする。
- 重複、同一通貨、10件到達時は追加ボタンを無効化し、理由を近くに表示する。
- 閉じる操作は管理画面を閉じるだけとする。

## 候補一覧

- 選択中のPoE版・リーグについて、直近24時間の公式Currency Exchange APIに登場した内部IDの和集合を候補とする。
- 選択した右通貨との直接取引がなくても候補へ表示し、登録できる。
- 一覧、検索、登録行は日本語名だけを表示する。
- 英語名は内部ID照合だけに使い、UIへ表示せず検索対象にしない。
- 検証済み日本語名がない新規品は、英語へ自動フォールバックせず候補へ表示しない。
- PoE 1／PoE 2それぞれのゲーム内Currency Exchangeメニューと同じカテゴリ名、順序、所属を使う。
- カテゴリ先頭へアプリ独自の`すべて`を追加する。
- `お気に入り`カテゴリは置かず、上部の登録済み一覧で代替する。
- 通常時は選択カテゴリで絞り込む。
- 日本語名検索中は選択カテゴリに関係なく全カテゴリを横断し、結果へ所属カテゴリを補助表示する。
- カテゴリ内は確認できる範囲でゲーム内順序を使い、順序不明の新規品だけ日本語名順で末尾へ置く。

## アイコン

- アイコンURLは公式Trade static API由来の検証済みカタログを使う。
- 画像本体を全件一括取得しない。
- メイン画面は登録済みペアのアイコン、管理画面は現在見えている候補だけをUIスレッド外で遅延取得する。
- 各アイコンは初めて表示する時だけ取得する。
- 取得済み画像を`%APPDATA%\\PoENavi\\poetore-icon-cache`へ永続保存し、次回以降の起動では再取得しない。
- 公式画像URLが変わった場合だけ新しい画像を取得する。
- 取得中、オフライン、未対応、取得失敗時は汎用プレースホルダーを表示する。
- 取得失敗時は次回表示時に再試行し、登録とレート表示を妨げない。

### PoE 1占いカード

- 個別カード絵を使わず、全カードへ共通アイコン1枚を使う。
- 共通画像は`16px-Divination_card_inventory_icon.png`（16×16 PNG）をアプリへ同梱する。
- 実装時の取得元は`D:\\Android共有用\\16px-Divination_card_inventory_icon.png`。
- 新カードもカテゴリ判定だけで同じ画像を使い、画像取得・キャッシュ対象から除外する。

### 初版の既知制限

- 共通カード対応後も、公式static画像URLがない9品（PoE 1が1品、PoE 2が8品）は初版ではプレースホルダー表示とする。
- 検証済み日本語名がない9品は、名前が確認できるまで候補一覧へ表示しない。

## 対象外

- 検索ウィンドウ上部の既存換算ボタン
- 任意の右側通貨。初版はDivine／Chaos／Exaltedの3択だけとする。
- クロス換算による疑似レート
- 10件を超える登録
- ドラッグ＆ドロップによる並べ替え
- 個別占いカード画像の取得
- 初版でのアイコン未対応9品の追加補完

## 受け入れ条件

- 初回だけ各PoE版のデフォルト1件が登録される。
- デフォルトを含む全行を削除でき、0件状態が再起動後も維持される。
- 最大10件を追加、削除、上下移動でき、操作ごとに即時保存・即時反映される。
- PoE版ごとに登録内容を分離し、同じPoE版のリーグ間で共有される。
- 直接取引だけを使用し、取引なし、価格未確定、通信失敗を区別できる。
- 登録件数に応じてメイン画面が縦へ自動調整され、10件をスクロールなしで確認できる。
- 日本語名検索、カテゴリ絞り込み、全カテゴリ横断検索が仕様どおり動く。
- 数値表示が最大4桁の有効数字となり、不要な小数末尾0が表示されない。
- 取得済みアイコンを再起動時に再取得せず、オフラインでもキャッシュまたはプレースホルダーで画面が成立する。
- 公式APIが1時間単位であることと、最新データ確認の意味が画面内で伝わる。
