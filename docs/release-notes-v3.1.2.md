# PoENavi v3.1.2 リリースノート

## Linux／Wayland環境の互換性改善

- WaylandセッションでXWaylandが利用可能な場合、Qtを自動的に`xcb`バックエンドで起動
- ソースから起動するたびに`QT_QPA_PLATFORM=xcb python main.py`を指定する手間を解消
- 利用者が`QT_QPA_PLATFORM`を明示している場合は、その設定を維持
- Windows、通常のX11、XWaylandを利用できない環境には影響しない安全な条件判定を追加

Linuxは引き続き非公式サポートです。この対応はQtのクリップボード互換性を改善するもので、
グローバルホットキー、キー入力送信、PoEウィンドウ判定など、Windows依存機能の動作を
保証するものではありません。

## 開発・保守

- 新リーグ開始時のTrade関連データを一括監査・更新する開発者向けコマンドを追加
- 公式Tradeの日英Items／Stats、Modメタデータ、pseudo定義などを候補領域で検証し、
  SHA-256固定、レビュー必須判定、原子的反映、失敗時ロールバックに対応
- v3.1.1基準でぽえとれの残タスク文書を再整理

これらの保守機能は開発者向けであり、通常利用時の検索・表示・通信動作には影響しません。
