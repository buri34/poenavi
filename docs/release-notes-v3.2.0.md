# PoENavi v3.2.0 リリースノート

## ぽえとれ AUTO-HIDEモード

- Awakened PoE Tradeに近いAUTO-HIDE価格検索モードを追加（初期ホットキー: `Ctrl + D`）
- 保持キーを押している間は検索結果を維持し、離してマウスを動かすと自動的に閉じる動作に対応
- 保持キーを押したまま検索画面へ移動、または画面内をクリックすると操作モードへ移行
- 操作モードで画面外へ移動すると、検索画面を閉じてPoEへフォーカスを戻す
- AUTO-HIDEの保持キーは設定画面で`Ctrl`または`Alt`から選択し、通常キーも任意に変更可能
- コンボボックスやWindowsのDPIスケーリングを考慮した画面内外判定を追加

従来の操作モード（初期ホットキー: `Alt + D`）も引き続き利用できます。

## 傭兵の召喚状の価格検索

- PoE 3.29で追加された「傭兵の召喚状」に対応
- 詳細コピーのビルド名から、`傭兵の召喚状 (ビルド名)`を特定して検索
- 傭兵のメインスキル、サポートジェム、Tierを検索条件として解析
- 初期表示ではメインスキルだけを表示し、専用ボタンからサポートジェムを展開可能
- サポートジェムの表示切替後も、メインスキルを含む検索条件のチェック状態を維持

## ウィンドウ操作の修正

- 最大化したPoEへフォーカスを戻す際、ウィンドウの最大化が解除される問題を修正
- 最小化時だけ復元処理を行い、最大化・通常表示の状態を維持
