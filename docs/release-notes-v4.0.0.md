# PoENavi v4.0.0 リリースノート

## PoE2のみになびに正式対応

- PoE2のキャンペーン進行に対応した「みになび」を追加しました
- エリア移動や進行状況に応じて、攻略手順とレイアウト情報を自動表示します
- 標準表示と、ゲーム画面を隠しにくいコンパクト表示を利用できます
- ガイドは詳細版へ統一し、PoE1とPoE2の進行状況を別々に保存します

## PoE2専用のVOICEVOX読み上げを追加

- PoE2のエリア入場時に、みになびの案内をVOICEVOXで読み上げられるようになりました
- 読み上げ速度、間の長さ、文末の無音時間、音量を設定できます
- 同じエリアで死亡してチェックポイントへ戻った場合など、同じ案内の連続読み上げを抑止します
- VOICEVOXが起動していない場合も、みになびの表示やPoENaviの動作は継続します

## 起動時の選択画面と共通UIを改善

- PoE1 / PoE2と、ぽえなび / ぽえとれの選択を1つの画面へ統合しました
- 選択内容を固定して次回から直接起動する設定を追加しました
- みになびの切替ボタンを「みになびをON」「みになびをOFF」と分かりやすくしました
- ユーザー向け設定画面から開発用のガイド編集ボタンを削除しました

## PoE2ぽえとれについて

- PoE2版ぽえとれは現在テスト中のため、このリリースでは選択・起動できません
- PoE1版ぽえとれは従来どおり利用できます
