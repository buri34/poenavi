# Phase 3 公式Currency Exchange価格 Windows実機プレイ試験

対象: PoE 1／PoE 2の価格表示、関連価格、換算レート、Expedition報酬、仮挿入・回収価値

## 試験量

- **最小合格セット**: P0の4件。目安15～25分
- **追加推奨**: P1の3件。対象アイテムを用意できた時だけ実施
- 相場は変動するため、記載したアイテム名は推奨例とする。価格の完全一致ではなく、出典、通貨、更新、表示経路を判定する
- 価格差だけで不合格にしない。`カレンシー交換 直近価格`とpoe.ninjaは集計方法が異なるため、正常でも値が違う

## 開始前

1. Windows確認用ミラーの`run_dev.bat`で起動する。
2. PoE 1は現在のPoE 1リーグ、PoE 2は現在のPoE 2リーグを選ぶ。
3. 初回だけ公式24時間データの同期を待つ。検索直後がpoe.ninja表示でも、同期完了後に同じアイテムが公式表示へ切り替われば正常。
4. 各ケースは`OK`／`NG`／`実施不能`で記録する。NG時だけスクリーンショットと使用アイテム名を残す。

## P0 必須

### P3-WIN-01: PoE 1の主価格とpoe.ninjaグラフ

**重要度:** 最重要
**推奨対象:** 覚醒のフラグメント（なければCurrency Exchange対応カレンシー）

1. PoE 1モードで対象アイテムを詳細コピーして検索する。
2. 価格欄と7日推移を確認する。

**合格条件**

- 主価格の出典が`カレンシー交換 直近価格`になる。
- 1 Divine未満ならChaos、1 Divine以上ならDivineで表示される。
- poe.ninjaの7日推移とリンクも残る。
- 読み込み完了後も価格が空欄にならず、画面が固まらない。

**重大NG**

- PoE 1なのにExalted基準になる。
- 公式価格は出るが7日推移が消える。
- 別リーグまたはPoE 2の価格が混ざる。

### P3-WIN-02: PoE 2の主価格・換算レート・モード分離

**重要度:** 最重要
**推奨対象:** Liquid Verisium、Omen of AmeliorationなどCurrency Exchange対応品

1. PoE 2モードへ切り替え、対象アイテムを検索する。
2. 検索ウィンドウ上部のDivine換算と、メインウィンドウのDivine換算を確認する。
3. 必要なら各換算欄を更新する。

**合格条件**

- 主価格の出典が`カレンシー交換 直近価格`になる。
- 1 Divine未満ならExalted、1 Divine以上ならDivineで表示される。
- 検索ウィンドウとメインウィンドウの換算元が`カレンシー交換 直近価格`になる。
- PoE 1で確認したChaos基準の値が残らない。

**重大NG**

- PoE 2なのにChaosを基準価格として表示する。
- 検索ウィンドウだけ公式で、メインウィンドウが別の出典になる。
- PoE 1とPoE 2のリーグ切替後に前モードの価格が残る。

### P3-WIN-03: 再起動時の24時間キャッシュ復元

**重要度:** 最重要

1. P3-WIN-01と02の後、ぽえとれを終了する。
2. 同じ時間内に再起動し、PoE 1とPoE 2で同じ対象を再検索する。
3. エクスプローラーで次を確認する。

`%APPDATA%\PoENavi\poetore-official-exchange\raw\<poe1|poe2>\<リーグ>\`

**合格条件**

- 保存済みデータから公式価格が復元され、初回24時間取得と同じ長い待ち直しがない。
- 同期完了後、使用したPoE 1／PoE 2リーグに1時間単位の`.json.gz`が24本ある。
- PoE 1とPoE 2が別フォルダに保存されている。
- 再起動前後で出典や基準通貨が変わらない。

**重大NG**

- 再起動のたびに24時間分を取り直す。
- 古い別リーグ、または別ゲームの価格が一時表示される。
- キャッシュ破損や例外で検索できなくなる。

### P3-WIN-04: PoE 2 Expedition報酬チェック

**重要度:** 最重要
**前提:** PoE 2の報酬選択画面を開けること

1. ぽえとれ上部からExpedition報酬チェックを有効にし、読取範囲とショートカットを設定する。
2. 実際の報酬選択画面でショートカットを押す。
3. 表示された報酬名、数量、Exalted換算価格を画面と見比べる。
4. 報酬画面を閉じる。

**合格条件**

- 画面にある報酬だけが、正しい行対応で表示される。
- 数量が価格へ反映され、同じ報酬の数量違いで合計価格も変わる。
- 公式対応報酬だけの画面では、OCR完了後に価格取得だけを待つ時間が目立たない。
- 報酬画面を閉じるとオーバーレイも消える。

**重大NG**

- 別行の価格を表示する、報酬名を取り違える、数量を無視する。
- 価格取得待ちで毎回長く固まる。
- 報酬画面を閉じても古い価格が残る。

## P1 追加推奨

### P3-WIN-05: 関連アイテム・素材価格

**推奨対象:** 覚醒のフラグメントなど、関連アイテム欄が出る品

1. 対象を検索する。
2. `関連アイテムの参考価格`欄と、各行へマウスを置いた時の出典を確認する。

**合格条件**

- 関連品名、価格、通貨、出典が行ごとに対応している。
- 主価格の読み込みが遅い場合でも、公式で解決できる関連価格が不必要に待たされない。
- 公式未確定の関連品だけpoe.ninja参考価格または価格なしになり、他の行まで消えない。

### P3-WIN-06: 仮挿入費用と装着済み素材の回収価値

**前提:** PoE 2のRune／Soul Core対応装備

1. 空きソケットのある装備をコピーし、仮挿入候補からRuneまたはSoul Coreを選んで検索する。
2. 可能なら、識別可能な素材が装着済みの装備も検索する。

**合格条件**

- 選択した素材と個数に応じて`仮挿入オーグメントの参考費用`が変わる。
- 装着済み素材を安全に識別できる場合だけ、素材価格とOrb of Extractionを使った回収価値が表示される。
- 出品がChaos建てでもExaltedへ換算され、桁違いの値にならない。
- 素材が曖昧、価格なし、対象外の場合に誤った回収推奨を出さない。

### P3-WIN-07: poe.ninjaフォールバック

**推奨対象:** Currency Exchange対象外のUnique装備など

1. PoE 1またはPoE 2で対象外品を検索する。
2. 価格欄と7日推移を確認する。

**合格条件**

- 出典が`poe.ninja 参考価格`になる。
- 7日推移とpoe.ninjaリンクが表示される。
- 公式対象外を無理に`カレンシー交換 直近価格`として表示しない。

## 実機で無理に再現しない項目

次は注入データを使う自動テストで確認済みのため、実プレイで再現しなくてよい。

- 過去相場から3倍超に外れ、直前時間・注文板・poe.ninjaの裏付けがない単発異常値
- 破損した1時間キャッシュだけの再取得
- poe.ninja通信失敗中の部分フォールバック
- ID欠落、同名衝突、PoE 1／PoE 2 APIの誤接続
