# 任意カレンシーレート表示 Windows実機確認

対象は、この文書を含む変更不可の`poenavi-windows-<commit>`スナップショットだけとする。
SMB上のファイルは編集せず、検証結果は同フォルダの
`tests/manual/poetore-custom-rate-display/windows-test-results.csv`へ別名コピーして記録する。

## 起動

1. スナップショット直下の`run_dev.bat`を起動する。
2. `User data: <snapshot>\.dev-user-data`と表示されることを確認する。
3. ぽえとれモードを選び、メイン画面を開く。

配布ビルドも確認する場合は、スナップショット直下の
`BUILD_RELEASE_FROM_SNAPSHOT.cmd`を実行する。この入口はSMBを直接ビルドせず、
Windowsローカルへ固定スナップショットをコピーし、公式Python 3.12と.NET 8を
検査・必要時導入してから成果物をSMBの専用出力先へ戻す。

## 実施順

`windows-test-results.csv`の`CR-WIN-01`から順に実施し、`結果`へ
`OK`／`NG`／`実施不能`、`証跡`へスクリーンショット名を記録する。

特に次を区別する。

- 正常同期後に直接約定がない: `取引データなし`
- 直接約定はあるが異常値判定中: `価格未確定`
- 通信失敗かつ24時間以内の前回値なし: `最新データを取得できません`
- 通信失敗かつ24時間以内の前回値あり: 前回値を残して`最終確認 ○時間前`

## アイコンのオフライン確認

1. オンラインで登録済み行と管理画面の候補を一度表示する。
2. `%APPDATA%\PoENavi\poetore-icon-cache`ではなく、開発起動時に表示された
   `.dev-user-data\poetore-icon-cache`へ画像が作られたことを確認する。
3. ネットワークを切断してぽえとれを再起動する。
4. 取得済み画像は残り、未取得画像はプレースホルダーでも操作可能であることを確認する。

## 報告

必須ケースにNGがあれば、ケースID、見えた文言、使用した左右通貨、PoE版、リーグ、
スクリーンショット名を記録する。全件OKでも、結果CSVは保存する。
